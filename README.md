# KOMEK AI
Node.js 18+ керек. Қосымша пакет орнату қажет емес.
1. `cp .env.example .env` — ішіне ADMIN_PASS, ANTHROPIC_API_KEY, SECRET жазыңыз.
2. `node server.js`
3. Сайт: http://localhost:3000 · Әкімші: http://localhost:3000/admin.html
Деректер: data/aids.json. Барлық жазба «тексерілмеген» күйінде; әкімші панелінде ресми дереккөзбен тексеріп, «расталған» белгісін қойыңыз.
